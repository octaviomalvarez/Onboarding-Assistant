# Guía de solicitud de accesos — Torre de Data

## ¿Cómo solicito acceso a una herramienta?

Los accesos se solicitan a través del portal interno de herramientas. El proceso es:
1. Ingresá al portal de accesos con tu cuenta corporativa
2. Buscá la herramienta que necesitás
3. Completá el formulario de justificación de negocio
4. La solicitud se envía al aprobador correspondiente
5. Recibirás una notificación por email cuando sea aprobado o rechazado

El tiempo de aprobación estándar es de 1 a 3 días hábiles.

## Accesos prioritarios para la Torre de Data

Estos son los accesos que necesitás gestionar en tu primera semana:

**MyTE** — carga de horas trabajadas
- Aprobador: tu People Lead
- Tiempo estimado: 1 día hábil

**VPN Corporativa** — acceso remoto a la red de Accenture
- Gestionado por: Mesa de Ayuda IT (it.support@accenture.com)
- Tiempo estimado: mismo día si se solicita antes de las 14hs

**Repositorios del proyecto** (GitHub / Azure DevOps)
- Aprobador: Tech Lead del proyecto
- Pedíselo directamente por Teams o email

**Confluence** — documentación del proyecto
- Aprobador: Tech Lead o PM del proyecto

**Jira / Azure DevOps Boards** — gestión de tareas
- Aprobador: Tech Lead del proyecto

## Herramientas específicas de Data

Dependiendo del proyecto, podés necesitar acceso a:

**Azure Data Factory / Databricks / Synapse**
- Aprobador: Tech Lead + Representante de Seguridad
- Tiempo estimado: 2 a 5 días hábiles (requiere justificación de negocio)

**Power BI Service**
- Aprobador: Responsable de Accesos (diego.torres@accenture.com)
- Tiempo estimado: 1 a 2 días hábiles

**Ambientes de desarrollo y producción**
- Los accesos a ambientes productivos requieren aprobación adicional del cliente
- Coordiná con el Tech Lead y el PM del proyecto

## ¿Qué hago si mi solicitud fue rechazada?

Si tu solicitud fue rechazada, el sistema te va a notificar el motivo. Las razones más comunes son:
- Justificación de negocio incompleta → completá el campo y volvé a enviar
- Acceso no corresponde a tu rol → consultá con tu Tech Lead si realmente necesitás ese acceso
- Falta aprobación del cliente → el Tech Lead o PM debe gestionar la aprobación del lado del cliente

Si creés que el rechazo fue un error, contactá a diego.torres@accenture.com.

# Herramientas y accesos — Torre de Data

## Stack tecnológico de la torre

La Torre de Data de Accenture trabaja principalmente con el ecosistema de Azure y herramientas de datos modernas.

**Cloud y datos:**
- Azure Data Factory — orquestación de pipelines
- Azure Databricks — procesamiento distribuido con PySpark
- Azure Synapse Analytics — data warehouse y analytics
- dbt (data build tool) — transformaciones SQL versionadas

**Visualización:**
- Power BI — reportes y dashboards corporativos
- Tableau — en proyectos con clientes específicos

**Lenguajes principales:** Python, SQL, PySpark

**Gestión de proyectos:** Jira o Azure DevOps (varía por proyecto), Confluence, Teams

## Cómo solicitar acceso a una herramienta

Para solicitar acceso a cualquier herramienta corporativa:

1. Ingresá al portal interno de accesos con tu cuenta corporativa
2. Buscá la herramienta que necesitás
3. Completá el formulario de justificación de negocio
4. El aprobador correspondiente recibe una notificación automática

El tiempo estándar de aprobación es de 1 a 3 días hábiles. Para accesos a herramientas de Azure, se requiere también la aprobación del Tech Lead del proyecto y en algunos casos del área de Seguridad.

Si tenés problemas con alguna solicitud de acceso, contactá a **Diego Torres** (diego.torres@accenture.com).

## MyTE — sistema de carga de horas

MyTE es el sistema para registrar las horas trabajadas. Tenés que cargarlas como mínimo antes del cierre de cada viernes.

Si todavía no tenés acceso, solicitalo a través del portal de herramientas o contactá a la Mesa de Ayuda IT (it.support@accenture.com). El tiempo de aprobación es de 1 día hábil.

## VPN corporativa

Para configurar la VPN:
1. Solicitá el instalador a la Mesa de Ayuda IT
2. Seguí la guía de configuración que te envían por email
3. Si la solicitud es antes de las 14 hs, el acceso se activa el mismo día

Ante problemas técnicos con la VPN, escribile directamente a it.support@accenture.com.
